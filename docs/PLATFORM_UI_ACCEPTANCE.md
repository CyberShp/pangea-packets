# 平台骨架与异常报文流程验收

日期：2026-09-10。

## 本轮范围

- 平台首页与应用切换；iBMC 项目列表和八个项目页面。
- iBMC 使用浏览器本地数据，支持资料记录、风险模块、路径、示例用例、设计确认、模拟批次、线索和复测。Skill 内容直接读取项目内六个入口文件；尚无 AI 调用。
- 异常报文保留现有 API，增加指定规则入口、执行阻塞提示、真实执行前确认及监听配置编辑。
- 本轮源码新增 Platform.tsx、platform-model.ts、platform.css、packet-flow.css；在现有 App.tsx 和 main.tsx 上增量接入。后端未修改；工作区原有未提交变更保留。

## 已知边界

- iBMC 为交互骨架；未验证真实资料解析、模型调用、扫描、渗透或结果回填。
- 异常报文未验证 SSH、真实网卡、监听触发、线上字节、业务影响和恢复。
- 监听器的方向设置在现有实现中用于 TCP seq/ack 继承；UI 明确提示不会自动交换 IP、MAC、端口。ICMP 严格匹配及已有 none 继承语义未扩展后端。
- 指定规则本轮提供长度、校验和、截断、填充；浏览器主流程重点验证长度规则。未应用候选仅保留在规则页，应用后的编辑随场景保留。
- 输入校验属于前端交互；未将后端扩展为完整安全准入服务。真实执行仍需人员核对授权、环境、旁路观测和恢复。

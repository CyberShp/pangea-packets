# Web/API 基础方法

方法 ID 是本包标识，不是官方标准编号。按产品事实选择；所有方法都遵守共享约定。以下为设计要点，须补充具体产品操作后才形成用例。

| method_id | 适用入口 | 验证思路与对照 | 关键判据与证据 | 恢复 |
| --- | --- | --- | --- | --- |
| WEB-XSS | 用户可控内容进入页面、日志或其他用户视图 | 记录输入到输出的位置和 HTML/属性/脚本上下文；先用无害唯一标记确认流向，再在隔离测试浏览器验证处理方式；区分反射、存储和客户端处理 | 原始响应、DOM、执行上下文；纯文本回显不等于脚本执行；应保持数据语义，非预期执行需证据 | 删除测试内容，清理测试会话 |
| WEB-SSRF | 服务端根据 URL 获取镜像、更新或其他资源 | 对照允许的受控地址与按产品策略应拒绝的受控地址；仅在批准范围设计重定向/解析后的目标约束验证 | 接收端带关联标记日志、服务端任务/出站证据；访问允许目标是正常能力，只有越过已确认边界才支持漏洞 | 取消测试任务、卸载测试镜像，确认资源释放 |
| WEB-UPLOAD | 文件上传、配置或包导入 | 用测试文件对照扩展名、声明类型、实际内容、文件名和大小规则；检查存储与后续解析是否遵循权限 | 拒绝或隔离结果、文件/任务状态、解析日志；上传成功不等于任意执行 | 删除测试文件并恢复配置，写入操作单独授权 |
| WEB-DOWNLOAD | 导出、下载、用户可控资源路径 | 用合成文件验证路径边界和对象归属；对照有权与无权访问同一测试资源 | 实际返回内容、身份、资源归属；只用脱敏合成秘密，不获取真实秘密 | 删除合成文件及导出任务 |
| WEB-AUTHZ | 账户、角色、敏感管理动作 | 同级测试账号跨对象验证与低权限到高权限动作分开；同时检查 UI 与 API；管理员正常对照 | 响应加账户/任务/配置基线；拒绝码伴随状态改变仍需报告；区分横向越权和垂直提权 | 恢复测试账户权限，撤销测试令牌 |
| WEB-SESSION | 登录、会话、注销、角色变更 | 验证未登录、过期、注销和角色变更后的会话；锁定测试需单独批准与解锁方案 | 会话与受保护操作结果、审计；凭据引用脱敏，不保存真实令牌 | 注销测试会话，确认测试账号可正常使用 |
| WEB-INJECTION | 数据进入命令、查询、模板等解释器，有资料或迹象支持 | 先确定具体解释器和数据路径，再设计无破坏性输入/对照；分别处理命令、查询和模板语义 | 错误或延时不能单独确认为注入；需相关执行/查询证据且排除正常波动 | 清理测试数据与任务；不设计数据破坏操作 |

文件处理测试需同时关联业务功能和漏洞机制，例如下载同时引用 WEB-DOWNLOAD 与 WEB-AUTHZ。方法覆盖不能替代产品接口和角色覆盖。
